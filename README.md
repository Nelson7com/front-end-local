# LocalLang Tanzania — Frontend

## Files
- `index.html` — page structure and content
- `style.css` — responsive layout, white/blue design, dark theme
- `script.js` — hero image slider (5 seconds), infinite tribe marquee, theme toggle, mobile menu, language swap, and conversation form demo

## Run
Open `index.html` in Chrome. An internet connection is needed for Google Fonts and the Unsplash images.

## Notes
- The hero image slider changes every five seconds.
- The 45-item tribe/language strip loops continuously and pauses on hover.
- The dark/light toggle and responsive mobile navigation work without a framework.
- The conversation form is a frontend demo only. Connect it to your LocalLang/FastAPI translation endpoint before using it for real translation.
- Image URLs are external placeholders and can be replaced with your own locally stored photos.
- The list of 45 community/language names is illustrative and should be verified against the project's trusted sources before publication.
